# Rithwik Malhotra - Portfolio

A dependency-free personal portfolio and resume website for GitHub Pages.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

Replace the placeholder email, GitHub URL, and portrait block in `index.html` with your own details before publishing.
